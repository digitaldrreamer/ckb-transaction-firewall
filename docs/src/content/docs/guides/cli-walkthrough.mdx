`@ckb-firewall/cli` is the operator-facing tool for inspecting and governing the blacklist registry.

Published on npm as [@ckb-firewall/cli](https://www.npmjs.com/package/@ckb-firewall/cli).

## Install

```bash
npm install -g @ckb-firewall/cli
```

Or use the one-line installer:

```bash
curl -fsSL https://raw.githubusercontent.com/digitaldrreamer/ckb-transaction-firewall/main/scripts/install-cli.sh | bash
```

## Inspect the live registry

```bash
ckb-firewall inspect
```

Reads the canonical testnet registry cell and prints all entries with their status (`active` or `EXPIRED`) and expiry dates.

## Check a specific address

```bash
ckb-firewall check --lock-args 0xabc123...
```

Returns immediately with whether the address is currently blacklisted.

## Governance flow

All registry changes go through governance. The proposal lives as a **local JSON file** until `execute` writes it on-chain.

<Steps>
1. **Propose** — create a proposal locally and start the 72-hour review window
2. **Export** — share the proposal JSON with other participants
3. **Import** — each participant receives and merges the proposal
4. **Vote** — each validator signs their vote with their private key
5. **Sign** — governance signers add secp256k1 signatures after the review window
6. **Execute** — build and submit the on-chain registry update transaction
</Steps>

```bash
# Create and share a proposal
ckb-firewall propose
ckb-firewall export --proposal <id> --out proposal.json

# Other participants import, vote, re-export
ckb-firewall import proposal.json
ckb-firewall vote --proposal <id> --vote yes
ckb-firewall export --proposal <id> --out proposal-voted.json

# After 72h review window + 3/5 yes votes: sign
ckb-firewall sign --proposal <id> --signer-index 0

# Execute on-chain
ckb-firewall execute --proposal <id>
```

For a complete walkthrough with explanations of each step, see [Blacklisting an Address](/guides/governance-blacklist/) and the [Governance Runbook](/operations/governance-runbook/).

## Track proposal status

```bash
ckb-firewall proposals
ckb-firewall proposals --status voting
ckb-firewall proposals --status approved
```
