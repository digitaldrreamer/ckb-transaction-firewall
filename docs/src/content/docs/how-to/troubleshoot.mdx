## Governance CLI errors

| Symptom | Page |
|---|---|
| `execute` fails: vote digest mismatch | [Fix: vote digest mismatch](/how-to/fix-vote-digest-mismatch/) |
| `vote` rejects key: "not in validator set" | Your pubkey is not committed by the `validatorMerkleRoot` in the registry — see [Join governance](/how-to/join-governance/) |
| `execute` fails: review window not met | The proposal anchor has not aged long enough. Check on-chain confirmation time and wait. |
| `execute` fails: threshold not met | Not enough yes-votes. Collect more validator votes via `vote` and `import`. |
