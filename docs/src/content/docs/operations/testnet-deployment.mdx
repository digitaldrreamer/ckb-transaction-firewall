<Aside type="note" title="Two different kinds of outpoints">
**Contract code cells** contain RISC-V binaries and are referenced by the firewall lock args. **The registry data cell** contains the live BLKL payload and is what the SDK and CLI read. They live at different outpoints.
</Aside>

## Live registry cell

```
tx_hash: 0xd841c6c1e0841ea58274a7a114cce505bc19503cca4ab2da07c060d10a436672
index:   0
```

This cell moves after each governance update. Always fetch the current outpoint before building spending transactions.

Fetch the live payload:

```bash
ckb-cli --url https://testnet.ckb.dev rpc get_live_cell \
  --tx-hash 0xd841c6c1e0841ea58274a7a114cce505bc19503cca4ab2da07c060d10a436672 \
  --index 0 \
  --with-data \
  --output-format json
```

Or via the SDK:

```ts
import { fetchRegistryPayload } from "@ckb-firewall/sdk";

const registry = await fetchRegistryPayload(
  "https://testnet.ckb.dev",
  "0xd841c6c1e0841ea58274a7a114cce505bc19503cca4ab2da07c060d10a436672",
  0
);
```

## Registry spec (for SDK config)

```ts
{
  codeHash:    "0x493f1700508125b0e281b8fb1d168b03bd5ef71480399dd59221224901a9cd09",
  hashType:    "type",
  typeIdValue: "0x9be0ad6e4e5039a64d9725ff037057c16ef59f126e3bdd9841b802f0e0a112fe",
  required:    true,
}
```

The `typeIdValue` identifies this registry instance. It changes when the registry is re-bootstrapped and remains stable across normal governance updates of that instance.

## Governance committee

The governance committee is 5 members with a 3-of-5 signing threshold. The canonical testnet registry was re-bootstrapped with rotated testnet-only governance keys and treasury metadata on 2026-05-31. **Never use these keys outside local or testnet environments.**

The committee pubkeys and the validator Merkle root are embedded in the BLKL v2 governance header of the registry cell.

## Registry treasury

The canonical testnet registry carries a v3 governance header with a discoverable
treasury lock script. The initial treasury seed cell is:

```
tx_hash: 0xd841c6c1e0841ea58274a7a114cce505bc19503cca4ab2da07c060d10a436672
index:   1
lock_hash: 0xc1f0fbfad334b1be673f268122d449449305403b01d008fc698acc41e70740f2
capacity: 1000 CKB
donation_address: ckt1qyqf3z9g5axlfcxwstn6gcz03l2q8l2xyt9q4erc0p
```

Anyone can donate testnet CKB to the same treasury lock. The CLI discovers
plain treasury cells from the lock script embedded in the registry. `ckb-firewall
inspect` and the GUI show blacklist pool usage and repeat this donation address
when usage reaches 70% or more.
