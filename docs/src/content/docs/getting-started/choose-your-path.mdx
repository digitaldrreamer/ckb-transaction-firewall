The firewall is a stack of components. Pick the ones that apply to your situation.

## I'm building a TypeScript or JavaScript wallet or dApp

Use the **TypeScript SDK** (`@ckb-firewall/sdk`) to run a pre-flight check before signing. If you're wrapping user wallet cells with the firewall lock, continue to the wallet integration guide.

<CardGrid>
  <LinkCard href="/guides/typescript-preflight/" title="Pre-flight check (TypeScript)" description="Fetch the live registry and reject blacklisted outputs before signing." />
  <LinkCard href="/guides/typescript-wallet-integration/" title="Wallet integration" description="Wrap a secp256k1 wallet cell with the firewall lock." />
</CardGrid>

## I want to run a working example right now

The `examples/` directory contains runnable code against the live testnet registry — wallet UI, AI agent gating, blacklisted-transfer safety test, and a Rust backend service. No mocked data.

<CardGrid>
  <LinkCard href="https://github.com/digitaldrreamer/ckb-transaction-firewall/tree/main/examples" title="TypeScript examples" description="Agent pre-flight, wallet feedback UI, blacklisted-transfer safety test." />
  <LinkCard href="https://github.com/digitaldrreamer/ckb-transaction-firewall/tree/main/examples/rust" title="Rust example" description="Backend preflight service that checks unsigned transactions before signing." />
</CardGrid>

## I'm building a Rust application or service

Use the **Rust SDK** (`ckb-transaction-firewall-sdk`). It mirrors the TypeScript SDK API and makes no RPC calls — you supply the live registry cell.

<CardGrid>
  <LinkCard href="/guides/rust-preflight/" title="Pre-flight check (Rust)" description="In-process blacklist check with no network dependency." />
</CardGrid>

## I'm a governance participant

Use the **CLI** (`@ckb-firewall/cli`) to inspect the registry, manage proposals, vote, and submit governance transactions. The **GUI** provides a visual interface for the same operations. No private key is required for anchoring or executing — the autonomous treasury funds both.
