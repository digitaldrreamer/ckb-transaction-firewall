If you are integrating the firewall for the first time, this is the shortest path:

<Steps>
1. Read [How to Use](/getting-started/how-to-use/).
2. Read the [overview](/getting-started/overview/).
3. Pick the [TypeScript SDK](/getting-started/typescript-sdk/) or [Rust SDK](/getting-started/rust-sdk/).
4. Use the [CLI quickstart](/getting-started/cli/) if you need to inspect or prepare registry updates.
</Steps>
