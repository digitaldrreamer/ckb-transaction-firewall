---
title: Rust SDK
description: Native Rust SDK for pre-flight blacklist checking — coming soon.
---

A native Rust SDK is planned. It will expose the same pre-flight policy as the TypeScript SDK in plain Rust data structures, suitable for embedding in Rust-based wallets, services, and tooling.

Until then, use the [TypeScript SDK](/getting-started/typescript-sdk/) or the [CLI](/getting-started/cli/).
