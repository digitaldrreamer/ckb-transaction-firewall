# Mainnet Rollout Checklist (Template)

## Pre-Rollout

- [ ] Contracts and artifact hashes verified.
- [ ] Governance approvals complete.
- [ ] Canary wallet list approved.
- [ ] Monitoring dashboards active.
- [ ] Incident bridge and escalation contacts confirmed.

## Canary Rollout

- [ ] Deploy to canary wallet cohort.
- [ ] Execute safe transaction sample and confirm pass.
- [ ] Execute blacklisted transaction sample and confirm reject.
- [ ] Monitor for error/cycle anomalies during canary window.

## Full Rollout

- [ ] Expand to full wallet cohort.
- [ ] Verify SDK preflight and on-chain decisions remain aligned.
- [ ] Confirm no unresolved critical/high incidents.

## Post-Rollout

- [ ] Publish post-deploy verification report.
- [ ] Archive run logs, tx hashes, and evidence links.
- [ ] Update stakeholder communication channels.
